# Чеклист интеграции OEM (публичный)

> Документ описывает текущую реализованную версию v0.
> Не является юридической гарантией или офертой.
> Ответственность за применимость в конечном изделии несёт OEM.

## 1. Scope and ownership

- [ ] Подтверждён scope: текущая интеграция только для однозонной версии.
- [ ] Зафиксированы зоны ответственности OEM за финальное изделие и нормативное соответствие.
- [ ] Команда интеграции ознакомлена с [Technical specification](/docs/technical-specification/).

## 2. Electrical and safety chain

- [ ] Проверена корректность подключения силовой цепи и исполнительных элементов.
- [ ] Подтверждена работа аварийного отключения (SSR + механический размыкатель).
- [ ] Проверены датчик температуры и канал измерения тока.
- [ ] Исключён любой прямой обход контура безопасности из UI/сети.

## 3. Configuration and commissioning

- [ ] Загружена конфигурация, соответствующая конкретной модели печи.
- [ ] Пройден commissioning-проход с валидным I_ref.
- [ ] Проверены ограничения режимов PROGRAM/MANUAL.
- [ ] Подтверждена политика OTA: обновление только в IDLE.

## 4. SELFTEST and startup gate

- [ ] SELFTEST проходит успешно перед разрешением нагрева.
- [ ] При fail-сценариях SELFTEST нагрев остаётся заблокирован.
- [ ] Процедура восстановления после SELFTEST FAIL согласована с эксплуатацией.

Подробности: [SELFTEST scope](/docs/selftest-scope/).

## 5. Failure-mode validation

- [ ] Проверены сценарии перегрева и отказа датчика.
- [ ] Проверены сценарии SSR stuck / heater open.
- [ ] Проверено поведение после ABORT (блокировка, без автопуска, требуется сброс оператором).
- [ ] Проверено безопасное поведение после watchdog/power-loss.

Подробности: [Failure modes](/docs/failure-modes/).

## 6. Network and observability

- [ ] HTTP/MQTT используются только для мониторинга/диагностики.
- [ ] Проверено отсутствие удалённого запуска нагрева по сети.
- [ ] Проверено поведение при медленном клиенте/сетевых задержках.

## 7. Acceptance gate

- [ ] Все критические сценарии завершены PASS-протоколами.
- [ ] Документированы ограничения, которые остаются на стороне OEM.
- [ ] Release в серию разрешён только после подписания OEM acceptance record.
