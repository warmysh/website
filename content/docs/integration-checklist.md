# Чеклист интеграции OEM

> Документация: Docs v0.1.
> Реализация: v0 (однозонная). Не является офертой. Ответственность за применимость в конечном изделии несёт OEM.

## 1. Область и ответственность

- [ ] Подтверждена область: текущая интеграция только для однозонной версии.
- [ ] Зафиксированы зоны ответственности OEM за финальное изделие и нормативное соответствие.
- [ ] Команда интеграции ознакомлена с [Технической спецификацией](/website/docs/technical-specification/).

## 2. Силовая цепь и контур безопасности

- [ ] Проверена корректность подключения силовой цепи и исполнительных элементов.
- [ ] Подтверждена работа аварийного отключения (SSR + контактор).
- [ ] Проверены датчик температуры и канал измерения тока.
- [ ] Исключён любой прямой обход контура безопасности из UI/сети.

## 3. Конфигурация и ввод в эксплуатацию

- [ ] Загружена конфигурация, соответствующая конкретной модели печи.
- [ ] Пройден пусконаладочный проход с валидным I_ref.
- [ ] Проверены ограничения режимов PROGRAM/MANUAL.
- [ ] Подтверждена политика OTA: обновление только в IDLE.

## 4. SELFTEST и предпусковой барьер

- [ ] SELFTEST проходит успешно перед разрешением нагрева.
- [ ] При сбое SELFTEST нагрев остаётся заблокирован.
- [ ] Процедура устранения после SELFTEST FAIL согласована с эксплуатацией.

Подробности: [Область SELFTEST](/website/docs/selftest-scope/).

## 5. Проверка реакций на отказы

- [ ] Проверены сценарии перегрева и отказа датчика.
- [ ] Проверены сценарии: залипание SSR / обрыв нагревателя.
- [ ] Проверено поведение после ABORT (аварийная блокировка, без автопуска, требуется сброс блокировки оператором).
- [ ] Проверено безопасное поведение после watchdog/power-loss.

Подробности: [Отказы и реакции системы](/website/docs/failure-modes/).

## 6. Сеть и наблюдаемость

- [ ] HTTP используется только для мониторинга/диагностики.
- [ ] Проверено отсутствие удалённого запуска нагрева по сети.
- [ ] Проверено поведение при медленном клиенте/сетевых задержках.

## 7. Приёмка

- [ ] Все критические сценарии завершены PASS-протоколами.
- [ ] Документированы ограничения, которые остаются на стороне OEM.
- [ ] Решение о выпуске в серию принимается OEM по процедурам OEM после подписания протокола приёмки.
