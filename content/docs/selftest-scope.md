# Область SELFTEST

_Соответствует прошивке 1.1.3 и новее._

Контроллер не включит нагрев, пока печь не докажет свою готовность: перед каждым
стартом выполняется полный цикл самодиагностики SELFTEST. Не пройден — нагрев
остаётся заблокированным.

## Зачем нужен SELFTEST

- подтвердить исправность датчиков, силовой части и конфигурации на момент старта;
- отсечь запуск на неисправном оборудовании до подачи мощности;
- дать оператору конкретную причину, если запуск невозможен.

## Состав проверок

SELFTEST выполняет следующие проверки перед разрешением нагрева.
Проверки делятся на две категории по реакции при сбое:

- **Блокирующая** — при сбое нагрев не разрешается до устранения причины.
- **Некритическая** — сбой фиксируется в журнале; нагрев может быть разрешён, но отдельные функции (например, продолжение программы) могут быть ограничены.

| # | Проверка | Реакция при сбое |
|---|----------|-----------------|
| 1 | Доступность файловой системы | Блокирующая |
| 2 | Целостность параметров конфигурации модели | Некритическая |
| 3 | Температурный тракт: показания термопары, биты отказа | Блокирующая |
| 4 | Дисплей | Не проверяется (не деструктивная) |
| 5 | Кнопки управления | Некритическая |
| 6 | Канал измерения тока (связь с измерителем) | Блокирующая |
| 7 | Ток в выключенном состоянии не превышает допустимый предел | Блокирующая |
| 8 | Начальная температура в допустимом диапазоне для старта | Блокирующая |
| 9 | Ток при включённом нагревателе | Блокирующая |
| 10 | Контроль отключения нагревателя | Некритическая |
| 11 | Валидность часов реального времени (RTC) | Некритическая; при сбое — продолжение программы недоступно |
| 12 | Целостность параметров эксплуатации | Некритическая |

**Важно для эксплуатации:** проверки силовой части (шаги 7–10) кратковременно
включают цепь нагревателя — на несколько секунд подаётся полная мощность.
Это штатное поведение холодного SELFTEST; печь при этом должна быть готова к включению.

По результатам токовых проверок вычисляется показатель **«Ресурс спирали»** —
оценка состояния нагревателя относительно эталона, отображаемая на экране диагностики.

## Критерии допуска и блокировки

PASS означает успешное прохождение SELFTEST (допуск к запуску нагрева).
FAIL означает блокировку запуска нагрева до устранения причины и повторной проверки.

### Условия допуска

- система может разрешить запуск нагрева по штатному сценарию.

### Условия блокировки

- нагрев остаётся запрещён;
- система остаётся в безопасном состоянии;
- требуется устранение причины и повторная проверка.

## Действия после сбоя SELFTEST

После сбоя SELFTEST выполняются действия:

- определяется причина отказа (датчик, силовая часть, конфигурация, состояние);
- причина отказа устраняется;
- выполняется повторный SELFTEST;
- запуск нагрева допускается только после PASS.

## Ограничения

- SELFTEST не гарантирует отсутствие отказов в процессе RUN;
- runtime-защиты и аварийные реакции продолжают работать независимо.
