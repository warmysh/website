# Отказы и реакции системы

> Документ относится к текущей версии документации: Docs v0.1.
> Публичная матрица типовых отказов и реакций системы.
> Не является юридической гарантией или офертой.
> Ответственность за применимость в конечном изделии несёт OEM.

## Критические отказы (→ ABORT)

| Отказ | Обнаружение | Реакция системы | Действия |
| --- | --- | --- | --- |
| Абсолютный/относительный перегрев | Логика температурных порогов | Переход в ABORT; нагрев OFF; SSR и контактор OFF; аварийная блокировка до сброса блокировки оператором | Проверка процесса и тракта датчика; сброс блокировки оператором |
| Отказ термопары (флаги MAX31856) | Флаги отказа датчика | Переход в ABORT; нагрев OFF; SSR и контактор OFF; аварийная блокировка до сброса блокировки оператором | Отремонтировать проводку/датчик; повторить SELFTEST |
| Залипание SSR / ток при команде OFF | Диагностика тока | Переход в ABORT; отключение силового тракта через контур безопасности; SSR и контактор OFF; аварийная блокировка до сброса блокировки оператором | Проверка SSR/силового тракта; замена неисправного узла; повторный SELFTEST |
| Обрыв нагревателя / критически низкий ток при высоком duty | Ток ниже ожидаемого диапазона | Переход в ABORT; нагрев заблокирован | Проверка целостности нагревателя и проводки; повторный SELFTEST |
| Логическая несогласованность (например, рост температуры при команде OFF) | Проверки правдоподобия в контуре безопасности | Переход в ABORT; нагрев OFF; SSR и контактор OFF; аварийная блокировка до сброса блокировки оператором | Диагностика силового тракта и канала управления; сброс блокировки оператором |
| Прерывание питания во время цикла | Логика возобновления после перезапуска + барьер SELFTEST | Безопасная перезагрузка; возобновление только при строгих условиях | Подтверждение условий возобновления или запуск из безопасного IDLE |
| Срабатывание сторожевого таймера (watchdog) | Таймаут сторожевого таймера | Аппаратная перезагрузка в безопасное состояние (нагрев OFF) | Диагностика причины зависания, подтверждение стабильности перед запуском |
| Сбой SELFTEST | Предпусковые проверки | Нагрев остаётся заблокирован | Устранение причины и повторный успешный SELFTEST |
| Медленный/перегруженный сетевой клиент | Контроль временного бюджета сервисного контура | Отключение клиента, приоритет контура управления сохранён | Нормализация сетевого контура; контур нагрева работает детерминированно |

## Предупреждения (Warning; нагрев продолжается)

| Событие | Обнаружение | Реакция системы | Действия |
| --- | --- | --- | --- |
| Деградация нагревателя (ток ниже порога предупреждения) | Измерение тока PZEM | Warning; нагрев продолжается; индикация на экране | Мониторинг тренда; плановая проверка нагревателя |
| Нет ожидаемого теплового отклика | Логика контроля дельты температуры | Warning; нагрев продолжается | Мониторинг процесса; проверка установки датчика и тракта нагрева |
| Перегрев холодного спая MAX31856 (CJ > 85 °C) | Регистр температуры MAX31856 | Warning; нагрев продолжается | Проверка вентиляции и теплового режима платы контроллера |
| Потеря связи с PZEM в режиме RUN | Тайм-аут UART-опроса | Warning; нагрев продолжается; токовая диагностика ограничена | Проверка проводки PZEM; после RUN — диагностика |

## Общая политика при отказах

- Контур безопасности имеет приоритет над UI и сетью.
- Критические отказы (→ ABORT): требуют явного действия оператора для сброса блокировки; нагрев не возобновляется автоматически.
- Предупреждения (Warning): нагрев продолжается; оператор видит предупреждение на экране и несёт ответственность за оценку ситуации.
- Удалённый обход safety-гейтов не допускается.
