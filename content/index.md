# Главная

Контроллер муфельной печи "PROFORGE Kiln Controller".

При обнаружении неопределённости контроллер останавливает нагрев.
Пока SELFTEST не завершён успешно, нагрев программно заблокирован.

---

## Архитектурные отличия

- Силовая цепь отключается двумя размыкателями: SSR и контактором.
- Контроллер измеряет ток нагревателя для диагностики силовой части.
- Перед разрешением нагрева обязателен SELFTEST.
- После аварии действует блокировка: SSR и контактор остаются отключёнными, нагрев не возобновляется автоматически.
- Интерфейс и сеть изолированы от силовой части и не выполняют прямое управление нагревом.
- Watchdog возвращает систему в безопасное состояние при зависании.

---

## Ограничения (намеренные)

- Протокол не реализует команд удалённого запуска нагрева.
- Запуск нагрева возможен только с физической панели.
- Автоматический перезапуск после аварийной остановки не выполняется.
- Публикуются только подтверждённые свойства текущей реализации.

## Реализованные возможности

- Программный режим: 13+ заводских программ обжига (рамп/выдержка, сегментные).
- Ручной режим: двухфазный bang-bang → PID.
- Продолжение программы после сбоя питания: три режима (EXACT_CONTINUE / REJOIN_RAMP / MANUAL_ONLY).
- OTA: обновление прошивки по воздуху, только в состоянии IDLE, с проверкой подписи манифеста.
- [Облачный мониторинг](/docs/cloud-monitoring/): телеметрия, история обжигов, уведомления — только чтение, без управления нагревом.
