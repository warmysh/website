## Добавленные фичи (найдены в коде, на сайте не были описаны)

- Полностью русский интерфейс (TFT + WebUI + облако) — ключевой аргумент для RU-рынка.
- Расчёт оставшегося времени обжига (eta_finish_s: экран, WebUI, облако).
- Предупреждение «слишком медленный набор температуры» (RampTooSlow) — в safety и failure-modes.
- Защита от циклических аварийных перезагрузок (анти-brick: ≥3 сбойных загрузок → нагрев блокирован) — в safety.
- Облако как PWA: добавление на главный экран телефона, push в браузере.
- Заметки к обжигу, энергия кВт·ч, график «программа против факта» — вынесены в продающие блоки.

## Открытые вопросы владельцу

1. **Две сессии одновременно правили сайт** — правки чуть не затёрли друг друга (спасла проверка mtime). Лучше вести сайт в одной сессии за раз.
2. Деплой: dist пересобран и обновлён локально; публикация на хостинг — за владельцем.
3. GitHub убран из контактов (решение параллельной сессии сохранено) — подтвердить.
4. SEO-кластер «модернизация старых печей» — большой спрос, но правило сайта запрещает упоминание брендов печей; делать ли отдельную посадочную без брендов?
5. В `_to_delete/` — снапшот параллельной версии и архивы сборки, можно удалять.
6. README сайта всё ещё объявляет «не продающий лендинг» — при новом курсе на продающий сайт стоит обновить контентные принципы.
